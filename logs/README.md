# Logs Directory

This directory contains audit and execution logs generated by Carnival Job Runner tasks.

- `updateInventory.log`: Logs of inventory sync runs.
- `updateDimensions.log`: Logs of style sizes and colors sync runs.
- `livedashPush.log`: Logs of LiveDash metric extraction and pushes.
- `logbookUpdateDB.log`: Logs of orders and tracking details extractions.

Files in this directory are git-ignored.
